# GRIMOIRE

**Live Site:** [https://sumith2425.github.io/grimoire/](https://sumith2425.github.io/grimoire/)

I wanted to read *Swordmaster's Youngest Son*, but the website I started reading on was full of bugs. When I pressed "Next" after Chapter 301, it randomly took me straight to Chapter 361. On top of that, some chapter URLs didn't even match the actual chapter numbers, and there wasn't a proper scrollable chapter list to select from. 

I got frustrated with the broken navigation and built this site so I could actually read without interruptions.

### What it has
- **Fixed Navigation:** Next and Previous buttons that actually take you to the right chapter by verifying the chapter number from the post itself instead of trusting broken links.
- **Scrollable & Searchable Chapter List:** A single combo-box and full chapter index to jump to any chapter directly.
- **Clean Black Reader:** Pure black background, adjustable font sizes, keyboard arrow navigation, and translator notes/clutter stripped out at the bottom.
- **Reading History:** Automatically saves the last chapter you read and tracks recently viewed chapters.

### Contributing & Adding Novels
This is just a personal project, but feel free to make open-source contributions to it. 

I plan to add more novels to this later, though I haven't decided which ones yet. If you want to add a novel yourself, feel free to open a PR—just make sure it uses the **best available translation**, not just any random or machine translation.
